# Capital Link - Governance & Employee Evaluation Portal
ระบบประเมินผลการปฏิบัติงานประจำปี คณะกรรมการและพนักงาน  
เครือ **บมจ.แคปปิตอล ลิ้งค์ ไฟแนนเชียล กรุ๊ป (CLFG)** และ **บจ.เครดิตฟองซิเอร์ แคปปิตอล ลิ้งค์ (CLC)**

---

## 📌 ภาพรวมระบบ (Overview)
เว็บแอปพลิเคชันสำหรับประเมินผลการปฏิบัติงานตามหลักการกำกับดูแลกิจการที่ดี (Corporate Governance) และการประเมินผลพนักงานสายงานกำกับดูแล (CU, IA, Risk) รองรับทั้งการประเมินแบบออนไลน์ และการทำแบบประเมินออฟไลน์ (Standalone HTML)

### 🌟 จุดเด่นสำคัญ:
1. **การประเมินคณะกรรมการ (ส่วนที่ 1–3):**
   * ส่วนที่ 1: การประเมินผลการปฏิบัติงานของคณะกรรมการทั้งคณะ
   * ส่วนที่ 2: การประเมินผลการปฏิบัติงานของกรรมการรายบุคคล (Self & Cross Evaluation)
   * ส่วนที่ 3: การประเมินผลการปฏิบัติงานของผู้จัดการใหญ่ (MD)
   * สเกลคะแนน 0, 1, 2, 3, 4 และ N/A (ตัด N/A ออกจากฐานการคำนวณ)
   * ตัดเกรดอัตโนมัติ: `< 0.50` ควรปรับปรุง | `0.50 - 1.49` พอใช้ | `1.50 - 2.49` ปานกลาง | `2.50 - 3.49` ดี | `≥ 3.50` ดีมาก

2. **การประเมินพนักงานสายงานกำกับ (ส่วนที่ 4 - CLC):**
   * ประเมินพนักงาน 3 สายงาน: CU (กำกับดูแล), IA (ตรวจสอบภายใน), RISK (บริหารความเสี่ยง)
   * รวม 20 ข้อ ข้อละ 0–5 คะแนน รวมเต็ม 100 คะแนน
   * ตัดเกรดอัตโนมัติ: `≥ 86` ดีมาก | `71 - 85` ดี | `50 - 70` ปานกลาง | `< 50` ควรปรับปรุง

3. **ระบบผู้ดูแลระบบ (Admin PIN: 2569):**
   * สรุปผลคะแนนและตัดเกรดภาพรวมพร้อมส่งออกรายงาน Excel (XLSX)
   * จัดการรายชื่อกรรมการและสิทธิ์การประเมิน
   * ระบบปลดล็อกฟอร์มให้กรรมการแก้ไข (Form Unlock Control)
   * ระบบสำรองข้อมูลอัตโนมัติ (Safety Auto-Snapshot) และกู้คืนข้อมูล (Disaster Recovery)
   * ศูนย์บันทึกประวัติการใช้งาน (System Audit Trail) 500 รายการล่าสุด พร้อมส่งออก CSV
   * สร้างลิงก์ส่งต่อเฉพาะบุคคล และดาวน์โหลดแบบประเมินออฟไลน์ (.html) สำหรับส่งทาง LINE

## 🚀 วิธีติดตั้งและรันบนเครื่องของคุณ (Local Setup)

### 1. ความต้องการของระบบ (Prerequisites)
* Node.js v18 หรือใหม่กว่า (แนะนำ Node.js v20 หรือ v22)
* npm หรือ yarn / pnpm

### 2. ขั้นตอนการติดตั้ง
\`\`\`bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นรันโปรแกรม (Development Mode)
npm run dev
\`\`\`

เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

### 3. คำสั่งสำหรับการ Build และ Production
\`\`\`bash
# Build สำหรับ Production
npm run build

# รันเซิร์ฟเวอร์ Production
npm run start
\`\`\`

## 🌐 การนำไป Deploy ขึ้นโฮสติ้งสาธารณะ (ฟรี & ไม่ติดล็อกอิน Google)

เมื่อนำโค้ดขึ้น GitHub แล้ว คุณสามารถนำไปเชื่อมต่อกับ Cloud Hosting ฟรีเพื่อเปิดให้กรรมการเข้าใช้งานได้ทันทีโดยไม่ต้องล็อกอิน Google:

### ทางเลือกที่ 1: Deploy บน Render (แนะนำ - ฟรี & ง่ายที่สุด)
1. สมัครสมาชิกที่ [render.com](https://render.com)
2. กดปุ่ม **New +** > เลือก **Web Service**
3. เลือก Repository จาก GitHub ของคุณ
4. ตั้งค่าดังนี้:
   * **Runtime:** Node
   * **Build Command:** `npm install && npm run build`
   * **Start Command:** `node server.ts`
5. กด **Deploy Web Service**
6. คุณจะได้ URL สาธารณะ เช่น `https://capitallink-eval.onrender.com` ที่กรรมการทุกคนเปิดทำได้ทันที 100%

### ทางเลือกที่ 2: Deploy บน Railway
1. สมัครสมาชิกที่ [railway.app](https://railway.app)
2. กด **New Project** > **Deploy from GitHub repo**
3. ระบบจะตรวจจับ Node.js และเริ่มรันแอปให้อัตโนมัติ
